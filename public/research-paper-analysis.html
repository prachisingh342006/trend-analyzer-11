Research Paper Analysis for the Social Media Trend Dashboard

This page explains how the five downloaded research papers support the AI model, the dataset dashboard, and the interpretation of the social media trend dataset used in the app.

Dataset size 5,000 posts
Platform coverage 4 platforms
Total views 12.5B

How the papers are used

AI model layer Weighted engagement scoring

The dashboard ranks segments using views, likes, shares, comments, engagement rate, and sample support, which aligns closely with the popularity-prediction and graph-based ranking ideas in the papers.

Trend monitoring Time-series and momentum

Monthly view patterns, recent momentum shifts, and platform-specific trend changes are grounded in the temporal and early-detection papers.

Research traceability Source and PDF for every paper

Each paper below includes the original source page and a local PDF download, so the analysis is explainable and presentation-ready.

Predicting Tweet Engagement with Graph Neural Networks
Marco Arazzi et al.		 Uses graph neural networks to improve engagement prediction for Twitter posts. Supports the AI model ranking layer and segment-level scoring logic. arXiv source Open PDF
Real-Time Classification of Twitter Trends
Arkaitz Zubiaga et al.		 Shows how early social signals classify different trend categories in real time. Supports the trend charts, fast-moving topic detection, and live monitoring angle. arXiv source Open PDF
DFW-PP: Dynamic Feature Weighting based Popularity Prediction for Social Media Content
Viswanatha Reddy G et al.		 Explains dynamic feature weighting for social-media popularity prediction. Supports the weighted scoring formula and top-opportunity segment leaderboard. arXiv source Open PDF
TWSSenti: A Novel Hybrid Framework for Topic-Wise Sentiment Analysis on Social Media Using Transformer Models
Aish Albladi et al.		 Uses transformer models for more robust social-media sentiment analysis. Supports the sentiment-aware extension and the research-paper mapping for text-heavy rows. arXiv source Open PDF
SMTPD: A New Benchmark for Temporal Prediction of Social Media Popularity
Yijie Xu et al.		 Builds a benchmark for temporal popularity prediction with time alignment. Supports the month-by-month dashboard, temporal forecasting, and long-window momentum analysis. arXiv source Open PDF
